# 灰盒方块颜色对照

| 颜色 | kind | 行为 |
|---|---|---|
| 灰 | terrain | 地形，实心，8px 网格 |
| 红 | hazard | 碰到立即死亡，回最近存档点 |
| 青 | crystal | 回满冲刺与体力，2.5s 后恢复 |
| 绿 | spring | 按地形自动判朝向，弹速 300 |
| 褐 | breakable | 冲刺窗口或速度>=240 撞碎，并清除视觉 |
| 紫 | dream | Dream Block：冲刺接触触发 Dream Dash，原速穿过，撞墙死亡 |
| 金 | checkpoint | 记录当前位置，死亡后在此复活 |

机关 4px 网格（Entities 层）；地形 8px 网格（Terrain 层）。
| 淡蓝 | oneway | 单向墙：按贴附地形自动判 4 个通行方向（下贴地→向上穿…），仅朝通行方向移动时穿过，其余实心 |

新增分大小/分方向 tile（实体图集共 11 个）：
| 颜色 | kind | 说明 |
|---|---|---|
| 棕 | breakable8 | 可破坏块，按 8×8 单位碎裂 |
| 深棕 | breakable16 | 可破坏块，按 16×16 单位碎裂 |
| 浅蓝 | oneway_up | 单向墙：向上穿过 |
| 青绿 | oneway_down | 单向墙：向下穿过 |
| 蓝紫 | oneway_left | 单向墙：向左穿过 |
| 亮绿 | oneway_right | 单向墙：向右穿过 |

画可破坏块时：选 4×4 画布涂出想要的整体形状，再选 breakable8/16 决定"每一块碎多大"。
单向墙：先决定通行方向选对应颜色，尺寸随意（4px 网格）。

## 单向墙（oneway_*）约定（v1.2）

四个方向**同一种颜色（深灰）**，靠 1px 黑色描边标出**可通行的一侧**：

| kind | 白边位置 | 可穿过方向 |
|---|---|---|
| oneway_up | 顶边黑边 | 向上 |
| oneway_down | 底边黑边 | 向下 |
| oneway_left | 左边黑边 | 向左 |
| oneway_right | 右边黑边 | 向右 |

在 TileMap 上放大预览时以白边位置区分方向；运行时行为不变。
