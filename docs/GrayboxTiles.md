# 灰盒方块颜色对照

| 颜色 | kind | 行为 |
|---|---|---|
| 灰 | terrain | 地形，实心，8px 网格 |
| 红 | hazard | 碰到立即死亡，回最近存档点 |
| 青 | crystal | 回满冲刺与体力，2.5s 后恢复 |
| 绿 | spring | 按地形自动判朝向，弹速 300 |
| 褐 | breakable | 冲刺窗口或速度>=240 撞碎，并清除视觉 |
| 紫 | dream | Dream Block：冲刺接触触发 Dream Dash，原速穿过，撞墙死亡 |
| 金 | checkpoint | 记录当前位置，死亡后在此复活 |

机关 4px 网格（Entities 层）；地形 8px 网格（Terrain 层）。
| 淡蓝 | oneway | 单向墙：按贴附地形自动判 4 个通行方向（下贴地→向上穿…），仅朝通行方向移动时穿过，其余实心 |

新增分大小/分方向 tile（实体图集共 11 个）：
| 颜色 | kind | 说明 |
|---|---|---|
| 棕 | breakable8 | 可破坏块，按 8×8 单位碎裂 |
| 深棕 | breakable16 | 可破坏块，按 16×16 单位碎裂 |
| 浅蓝 | oneway_up | 单向墙：向上穿过 |
| 青绿 | oneway_down | 单向墙：向下穿过 |
| 蓝紫 | oneway_left | 单向墙：向左穿过 |
| 亮绿 | oneway_right | 单向墙：向右穿过 |

画可破坏块时：选 4×4 画布涂出想要的整体形状，再选 breakable8/16 决定"每一块碎多大"。
单向墙：先决定通行方向选对应颜色，尺寸随意（4px 网格）。

## 单向墙（oneway_*）约定（v1.2）

四个方向**同一种颜色（深灰）**，靠 2px 黑色描边标出**可通行的一侧**：

| kind | 白边位置 | 可穿过方向 |
|---|---|---|
| oneway_up | 上两行黑 | 向上 |
| oneway_down | 下两行黑 | 向下 |
| oneway_left | 左两列黑 | 向左 |
| oneway_right | 右两列黑 | 向右 |

在 TileMap 上放大预览时以白边位置区分方向；运行时行为不变。

## 房间与相机切换（蔚蓝式）

不需要"标志点"，而是**房间矩形**：
1. 在关卡根节点下新建 Node2D，命名 `Rooms`
2. 在 Rooms 下添加 Node2D 子节点，各自附加脚本 `scripts/components/room_area.gd`
3. 设置每个节点的 `position`（房间左上角）与 `rect_size`（房间尺寸，像素）
4. 运行时玩家跨入另一个房间矩形 → 相机停顿 0.16s → 0.16s 平滑滑到新房间视角
   - 小房间（<= 视口）锁定居中；大房间跟随玩家并夹在房间边界
5. 没有 Rooms 容器时相机保持原来的自由跟随

### 更省事：RoomsDefinition（推荐）

模板场景已带一个 `Rooms` 节点（脚本 `rooms_definition.gd`）：

1. 选中 `Rooms` → Inspector 里直接编辑 `rooms` 数组（Rect2 列表，position/size 即可）
2. 或者点 Inspector 上的 **「按屏幕网格自动生成房间」** 按钮：扫描 `Terrain` 覆盖范围，按 `room_size`（默认 320×184）自动铺网格房间
3. 生成后可在数组里删/改；相机自动按这些矩形切换

不需要手动创建子节点或挂脚本。
